🎧 DeepFake Audio Detection System  
AI-Based System to Detect Real vs Fake Audio

DeepFake Audio Detection is a machine learning-powered web application that analyzes uploaded audio files and predicts whether the audio is real or AI-generated (fake). It uses a trained ML model integrated with a Python backend and a simple responsive frontend interface.

✨ Features
- Upload audio file for analysis  
- Detects real vs fake audio using ML model  
- Fast prediction using trained scaler + model pipeline  
- Simple and responsive web UI  
- Backend API integration (FastAPI / Flask)  
- Secure audio processing and storage  
- Real-time prediction system  
- Call alert system when suspicious/fake audio is detected  
- Instant notification on detection result
